# Identité visuelle « The Last Escapor »

Couleurs : nuit `#06090F` → `#18233A`, os `#ECE4D3`, rouge `#FF3B2F`.
Polices (Google Fonts, libres) : **Anton** (ESCAPOR), **Barlow Condensed** ExtraBold (THE LAST, textes).

## Logo / icône
Fenêtre barricadée par deux planches, deux yeux rouges dans la fente (même code que les yeux des zombies en jeu).

| Fichier | Usage |
|---|---|
| `icon_1024_carre.png` | Unity Player Settings (Default Icon), Quest / Android, iOS (pas de transparence, la plateforme arrondit) |
| `icon_1024_arrondi.png` | Bureau, README, présentations |
| `icon_macos.icns` | Build Mac |
| `icon_windows.ico` | Build Windows (16 à 256 px, version simplifiée en dessous de 64 px) |
| `icon.svg` | Vectoriel source |
| `logo_horizontal_transparent.png` | Logotype horizontal, fond transparent (pour fond sombre) |
| `logo_vertical_fond_nuit.png` | Logotype vertical sur fond nuit |

Tailles 16-512 px, icône adaptative Android et scripts de génération : dossier branding/ du projet Claude, sur demande.

## Cover
Plan de la cinématique de fin (les zombies bloqués derrière la grille), grille redessinée (barreaux ronds en fer forgé, rouille, bagues, traverse rivetée, plaque boulonnée), étalonné nuit, yeux rouges ajoutés.
- `../cover.png` (`docs/images/cover.png`, 1280x640) : cover du README et aperçu social GitHub (Settings > General > Social preview, sous la limite de 1 Mo)
- `cover_2560x1280.png` : haute définition
- `cover_1920x1080.png` : 16:9 (itch.io, diaporama, vidéo)
